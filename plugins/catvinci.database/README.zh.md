# 数据库视图

把一个文件夹里的文档显示成表格、看板、日历或画廊，相当于 Notion 的数据库，但存的仍是普通 Markdown 文件。每篇文档是一行，文档开头属性（front matter）里的各项就是各列：

```markdown
---
start: 2026-01-05
end: 2026-01-11
focus: [研究]
rate: 4
---

# 第 2 周
```

在任意文档里放一个 `database` 块（输入 `/数据库` 或选择**新建数据库…**），它就会显示文档旁边那个文件夹：

````markdown
```database
from: 2026 日历
view: table
sort: start
```
````

- **表格**：点单元格就能改，对应文档的属性跟着改。点页面名可以改名（文件和指向它的链接一起改），旁边的 ↗ 打开页面。表格底部的 **+ 新建** 直接输入标题建一页。
- **属性类型**和 Notion 一样：文本、数字、单选、多选、日期、复选框、网址。单选和多选点开是选项列表，可以搜索，也可以直接输入新选项；每个选项有自己的颜色。几个短词反复出现的列（比如 status）自动当作单选。
- **列的菜单**：点列名可以升序、降序、按它筛选、改类型、重命名（所有页面里一起改）、隐藏或删除这个属性。最右边的 **+** 新增属性，或把隐藏的列显示回来。
- **筛选和排序**：上方的**筛选**、**排序**按钮打开规则菜单，可以加多条；正在生效的规则显示在下面，点一下就能修改。
- **看板**：按单选属性分列（像 Notion 按状态分列），没有就按多选属性；也可以写 `group: owner`。拖卡片到另一列就改了它的值，每列底部可以直接新建。
- **日历**：每个页面放在它的日期上（`date: start`），有 `end` 就一直延续到结束那天。双击某一天新建一个当天的页面。
- **画廊**：每个页面一张卡片，带它的 `cover` 图片或 `icon`。

这些设置都记在块里，看得懂也能手改：`columns: start, focus`（显示哪些列、什么顺序）、`sort: -rate`（`-` 表示倒序）、`filter: focus has 研究`（`=`、`!=`、`has`、`!has`、`>`、`<`、`empty`、`!empty`，每行一个）、`group:`、`date:`、`end:`、`types: status=select`（属性类型）。

**从 Notion 导入**：在 Notion 里把数据库导出为 Markdown & CSV，解压到打开的文件夹里，在侧边栏右键它的 `.csv`，选择**从 Notion 导入…**。每个页面都会变成一篇文档，属性写进开头，并附带一个展示它们的页面。

**用 Textus AI**：直接说"做一个 2026 年的周历，记录每周重点和评分"，它会建好文件夹、各个页面和这个块。
