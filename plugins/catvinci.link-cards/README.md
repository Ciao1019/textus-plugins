# Link Cards

A link as a card: its page's title, description and picture, the site's name - click it to open the page. A YouTube or Bilibili video plays in the card instead.

- Type `/card` (or choose **Insert Link Card…**) and paste a link; or select a link and right-click it.
- The card is a `card` block holding what the page said, so it shows without the network and reads as text in any Markdown app:

````markdown
```card
url: https://textus.catvinci.com
title: Textus
description: A Markdown editor with AI that writes with you.
image: https://textus.catvinci.com/og.png
```
````

- **Fetch again** under a card brings the page's latest title and picture.

To read pages, the plugin asks to reach any web address; it fetches only the links you make cards of.
