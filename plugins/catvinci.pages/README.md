# Pages

Documents as pages inside pages, as in Notion, kept as plain Markdown files.

- **A sub-page** of `Plans.md` is a document in the folder beside it called `Plans/`. Type `/page` (or choose **New Sub-page…**) to make one: it is created there, linked from where you are with a `[[wiki link]]`, and opened.
- **The Pages tab** in the sidebar shows the open folder as a tree of pages: each page opens with its sub-pages under it. Right-click one for a new sub-page or its icon.
- **A page icon** is an emoji in the page's front matter (`icon: 📅`), shown in the tree. **Set Page Icon…** picks one.
- **Where you are**: in a sub-page, the status bar shows the pages above it - `Life › 2026 Calendar › Week 1`. Click it to go up to one.

Nothing is stored anywhere but your files: other Markdown apps see ordinary documents, folders and links.
