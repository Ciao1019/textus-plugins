# 页面树

像 Notion 一样把文档组织成页面里的页面，存的仍然是普通 Markdown 文件。

- **子页面**：`计划.md` 的子页面就是它旁边 `计划/` 文件夹里的文档。输入 `/页面`（或选择**新建子页面…**）新建一个：文件建在那里，当前位置插入指向它的 `[[双向链接]]`，然后打开它。
- **侧边栏的“页面”标签**把打开的文件夹显示成页面树，每个页面下面是它的子页面。右键可以新建子页面或设置图标。
- **页面图标**是写在页面开头属性里的一个表情（`icon: 📅`），显示在页面树里。用**设置页面图标…**来选。
- **当前位置**：在子页面里，状态栏会显示上级页面，比如 `生活 › 2026 日历 › 第 1 周`，点击即可跳到上级。

除了你的文件，不额外保存任何东西：别的 Markdown 软件看到的只是普通的文档、文件夹和链接。
