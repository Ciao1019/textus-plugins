# 提醒

在任意一行（待办、标题都可以）写上 `(@2026-11-02 09:00)`，到时会弹出系统通知提醒你这一行，点通知就会打开它。

- 只写 `(@2026-11-02)` 会在当天早上 9 点提醒。
- 输入 `/提醒`（或选择**提醒我…**）会帮你插入时间标记：一小时后、今晚、明天、下周一，或自己输入的时间。
- 打了勾的待办（`- [x] …`）算已完成，不再提醒。
- 侧边栏的**提醒**标签列出即将到来的提醒。
- 提醒由 Textus 自己记着：有窗口开着时会准时提醒；打开设置 › 通用里的**在后台保持运行**后，窗口全关了也照样提醒。Textus 没运行时错过的提醒，会在下次启动时补上。

标记的写法与 Obsidian 的 Reminder 插件相同，同一份笔记在那边也能提醒。
