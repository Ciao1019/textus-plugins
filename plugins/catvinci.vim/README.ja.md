# Vim

エディタで Vim のモードとキーを使えます。

- **プラグイン › Vim キーのオン・オフ** で切り替えます。
- ノーマル、挿入、ビジュアルの各モードで、移動、オペレータ、カウント、レジスタ、**.** での繰り返しが使えます。
- 一「行」は段落、見出し、リスト項目、またはコードブロックの一行です。**j** と **k** ですべてを行き来でき、**}** と **{** はブロックごとに移ります。**zz**・**zt**・**zb** でカーソル行をウィンドウの中央・上端・下端に移します。
- **~** でカーソル位置の文字の大文字・小文字を入れ替えます。ビジュアルモードでは **~**、**U**、**u** で、選択範囲をそれぞれ入れ替え・大文字・小文字にします。
- **s** と一文字のあとにラベルを押すと、画面上のどこへでもジャンプできます（flash）。カーソルに近い場所ほど先にラベルが付きます。**s** の前に **d**、**c**、**y** を押すと、そこまで削除・変更・コピーします。
- **:** でコマンドパレットを開きます。Vim のコマンドが先頭に並びます。**:w** で保存、**:q** でタブを閉じ、**:wq** で両方、**:12** で 12 行目へ移ります。Textus のほかのコマンドもここで探せます。
- Mac では、ノーマルモードの間は英字入力になるので、日本語入力にキーを取られません。挿入モードに戻ると元の入力ソースに戻ります。
- プラグインの設定の**キーマッピング**には、vimrc と同じく一行に一つずつ書けます。たとえば `inoremap jj <Esc>` や `nnoremap <leader>w :w<CR>`。flash もそこでオフにできます。
