# Vim

편집기에서 Vim의 모드와 키를 쓸 수 있습니다.

- **플러그인 › Vim 키 켜기/끄기**로 전환합니다.
- 노멀, 삽입, 비주얼 모드에서 이동, 연산자, 횟수, 레지스터, **.** 반복을 쓸 수 있습니다.
- 한 "줄"은 문단, 제목, 목록 항목, 또는 코드 블록의 한 줄입니다. **j**와 **k**로 모두 오갈 수 있고, **}**와 **{**는 블록 단위로 움직입니다. **zz**, **zt**, **zb**는 커서가 있는 줄을 창의 가운데, 위, 아래로 옮깁니다.
- **~**는 커서 아래 글자의 대소문자를 바꿉니다. 비주얼 모드에서 **~**, **U**, **u**는 선택한 내용을 각각 대소문자 바꾸기, 대문자로, 소문자로 만듭니다.
- **s**와 한 글자를 누른 뒤 레이블을 누르면 화면 어디로든 이동합니다(flash). 커서에 가까운 곳부터 레이블이 붙습니다. **s** 앞에 **d**, **c**, **y**를 누르면 그곳까지 지우기, 바꾸기, 복사를 합니다.
- **:**로 명령 팔레트를 엽니다. Vim 명령이 맨 앞에 옵니다. **:w**는 저장, **:q**는 탭 닫기, **:wq**는 둘 다, **:12**는 12번째 줄로 이동하며, Textus의 다른 명령도 여기서 찾을 수 있습니다.
- Mac에서는 노멀 모드 동안 영문 입력으로 바뀌어 한글 입력기가 키를 가로채지 않습니다. 삽입 모드로 돌아가면 원래 입력 소스로 돌아옵니다.
- 플러그인 설정의 **키 매핑**에는 vimrc처럼 한 줄에 하나씩 씁니다. 예: `inoremap jj <Esc>`, `nnoremap <leader>w :w<CR>`. flash도 거기서 끌 수 있습니다.
