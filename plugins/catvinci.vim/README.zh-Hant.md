# Vim

在編輯器中使用 Vim 的模式和按鍵。

- 選擇 **外掛程式 › 開啟或關閉 Vim 按鍵** 來切換。
- 一般、插入、可視三種模式，支援移動、運算子、計數、暫存器，以及用 **.** 重複。
- 一「行」是一個段落、標題、清單項目，或程式碼區塊裡的一行：**j** 和 **k** 能走遍它們，**}** 和 **{** 按區塊跳。**zz**、**zt**、**zb** 把游標所在行移到視窗中間、頂部或底部。
- **~** 切換游標處字母的大小寫；在可視模式下，**~**、**U** 和 **u** 分別把選取內容切換大小寫、改成大寫、改成小寫。
- 按 **s** 加一個字母，再按標籤，就能跳到畫面上任何位置（flash），離游標近的位置先拿到標籤。先按 **d**、**c** 或 **y** 再按 **s**，就是刪除、修改或複製到那裡。
- 按 **:** 開啟命令面板，Vim 的命令排在最前：**:w** 儲存，**:q** 關閉分頁，**:wq** 儲存並關閉，**:12** 跳到第 12 行；Textus 的其他命令也能在這裡搜到。
- 在 Mac 上，一般模式下會暫時切到英文輸入，注音、拼音等輸入法不會攔住按鍵；回到插入模式，原本的輸入法自動回來。
- 外掛程式設定中的**按鍵對應**像 vimrc 一樣一行一條，例如 `inoremap jj <Esc>` 或 `nnoremap <leader>w :w<CR>`。flash 也可以在那裡關掉。
